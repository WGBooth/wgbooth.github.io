## The Long Story
For my Network Packet Analyzer project, I added views to analyze TCP and DNS traffic on the Streamlit dashboard and the ability to filter by protocol, IP address, and port. The filters have lists generated by the packets captured in descending order of frequency. This part of the project helped me dive into DNS and TCP protocols in a way that reading a textbook wouldn't cover, and there's still more for me to learn! For example, I didn't realize how many different types of DNS queries existed beyond IPv4 (A), IPv6 (AAAA), mail exchange (MX), and name server (NS) queries. Just look at the chart.

![DNS Query Dashboard](/assets/images/dns_screenshot.png)

PTR is a DNS pointer. It is used for reverse DNS lookup, so instead of starting with a domain name, like colorado.edu, it starts with the IP address.

This is from [Cloudflare](https://www.cloudflare.com/learning/dns/dns-records/dns-ptr-record/):

"While DNS A records are stored under the given domain name, DNS PTR records are stored under the IP address — reversed, and with ".in-addr.arpa" added. For example, the PTR record for the IP address 192.0.2.255 would be stored under "255.2.0.192.in-addr.arpa"."

In the Ultimate Capture File, a capture file I found online, shows the number of TCP connections, including handshakes and the result of the connection (closed, reset, or still open) by the end of the capture.

![TCP Connections Dashboard](/assets/images/tcp_screenshot.png)
