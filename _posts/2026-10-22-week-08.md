## Highlights

- First dashboard built for visualizing network traffic
- Supports file upload, live capture, and remote capture

## The Long Story

I've got a dashboard working for the project using streamlit. It can read a capture by uploading a .pcap file, live capture from a network interface, or remote capture from an ssh connection on a local machine. Once captured, it performs some analysis of the network traffic, including packet counts, byte totals, protocol distribution, and top conversations before displaying it on the dashboard. Here's a couple screenshots of the capture from file from a large test file I found online.

![Top conversations](/assets/images/ultimate_tops.png)

For capturing live traffic or remote, the dashboard has a dropdown for detected interfaces to monitor traffic. Here's a couple screenshots: one is same device and the other is remote where the dropdown shows the detected interfaces for that machine.

Next week my goal was to expand the dashboard with filters by protocol/IP/port, traffic-over-time graph, top talkers, DNS activity, TCP connection summaries. My TCP conversation function still needs some work in identifying the SYN, SYN-ACK, and FIN flags correctly, but I wanted to get the dashboard up and not lose time messing with that at the moment.

I'm at a place where I am ahead on a couple elements and behind on some others so my potential impediment could be balancing out how much to reach back and how much to press on with the dashboard.

I think I could improve my process by committing to git more frequently. I have this habit of working on things and not committing incrementally. Not good for a variety of reasons: what if something happened to the computer I am working on, or there's a major bug? I'm going to correct this, starting... now.
